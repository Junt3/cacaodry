📋 Comandos de Administración

top
Muestra procesos en tiempo real y consumo de recursos
df -h
Muestra espacio en disco de forma legible (-h = human readable)
free -h
Muestra uso de memoria RAM y swap de forma legible
uptime
Muestra tiempo que lleva encendido el sistema y carga promedio
whoami
Muestra el nombre de usuario actual
uname -a
Muestra información completa del sistema operativo
ps aux
Muestra todos los procesos en ejecución con detalles
systemctl status
Muestra estado de todos los servicios del sistema
systemctl list-units --type=service --state=running
Lista solo los servicios que están actualmente activos
netstat -tlnp
Muestra conexiones de red y procesos asociados
ss -tlnp
Alternativa moderna a netstat para mostrar conexiones
sudo -u postgres psql -l
Lista todas las bases de datos disponibles
sudo -u postgres psql -c "\dt"
Lista todas las tablas de la base de datos actual
sudo -u postgres psql -c "SELECT * FROM pg_stat_activity;"
Muestra todas las conexiones activas a PostgreSQL
sudo -u postgres psql -c "SELECT pg_size_pretty(pg_database_size(current_database()));"
Muestra el tamaño de la base de datos actual
sudo -u postgres psql -c "SELECT schemaname, tablename, pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) FROM pg_tables WHERE schemaname='public' ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC LIMIT 10;"
Muestra las 10 tablas más grandes de la base de datos
sudo -u postgres psql -c "VACUUM ANALYZE;"
Optimiza la base de datos y actualiza estadísticas
sudo systemctl status postgresql
Muestra el estado del servicio PostgreSQL
sudo systemctl restart postgresql
Reinicia el servicio PostgreSQL
journalctl -xe
Muestra los errores más recientes del sistema
tail -f /var/log/syslog
Muestra en tiempo real el log del sistema
tail -f /var/log/auth.log
Muestra en tiempo real los logs de autenticación
dmesg | tail -50
Muestra los últimos 50 mensajes del kernel
ip addr
Muestra todas las interfaces de red y sus IPs
ip route
Muestra la tabla de enrutamiento
ping -c 4 8.8.8.8
Prueba conectividad con Google (4 paquetes)
curl -I https://google.com
Prueba conexión HTTP y muestra cabeceras

💡 Estos son los comandos más utilizados para administración del sistema. Escríbalos manualmente en la terminal SSH.
